# @filipeesch/dsh-design-bundle

Installable DSH bundle for the design plugin. The bundle ships the host service,
the preset-scoped design tools and auto-validation, the design preset
registration, the embedded client contribution, and the built renderer.

Install with `dsh plugin --profile <profile> add link:<checkout>/packages/bundle`
after `pnpm run build` in this repository. See the repository README for
install, update, and removal.
